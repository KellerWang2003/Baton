# iPhone frame

`iphone-16-pro-black.png` is the iPhone 16 Pro Black Titanium bezel from
[weirdapps/mockups](https://github.com/weirdapps/mockups), distributed under
the accompanying MIT license. The repository identifies these as Apple device
frames. The image is used unmodified, with the live prototype below its
transparent screen area.

Image: 1406 × 2822 px. Screen: 1206 × 2622 px at (102, 100).
